A skill fails quietly. It points at a file nobody copied, claims a trigger another skill already owns, or carries a description too vague to route on. Nothing errors.

Not run here

  • broken-reference - a browser has no filesystem, so whether a referenced file exists cannot be checked. lintSkills() takes that check as an injected option and skips the rule when it is missing rather than guessing.
  • name-mismatch - compares the frontmatter name against the skill's directory, and pasted text has no directory. Handing it one equal to the name would make the rule pass every time, which is not the rule passing.

Both run in the CLI, where there are real files to look at.
